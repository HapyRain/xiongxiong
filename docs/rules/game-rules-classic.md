# 经典模式（MVP）规则

> 定位：**一局定胜负**的极简模式，还原"课间随手来一局"。
> 状态：**已实现**（`GameRules.PRESETS.classic`；对应前端「单人 → 经典模式」）。
> 结算细节沿用 `game-rules-v2.md` §3 矩阵的子集，不另写一套逻辑。

---

## 1. 对局结构

| 项 | 规则 |
|---|---|
| 血量 | **1**（被打中即负，一局定胜负） |
| 盾 | 开局 **3**，上限 3 |
| 气 | 开局 **0**，上限 **5** |
| 回合 1 | **开局亮相**：双方强制攒气，气 +1（盾已满 3，不叠加） |
| 可用动作 | **攒气 / 包子（单发，不能多连）/ 防御** |
| 胜负 | 一方血量归零 → 该方负 |
| 回合上限 | **40 回合**；无人死亡 → 比血，血同判平（双方各 1 → 恒为平局） |

## 2. 动作与结算

| 动作 | 耗气 | 效果 |
|---|---|---|
| **攒气** | 0 | +1 气、+1 盾（各自封顶）；**本回合无防御** |
| **包子** | 1 | 对无防御者 → **掉 1 血（即死）**；对普通防御 → 被挡 |
| **防御** | 耗 1 盾（需盾 ≥ 1） | 挡下本回合的包子；**使用即扣 1 盾** |

对撞：

- **包子 vs 包子**：互相抵消，双方无事
- **包子 vs 防御**：被挡，防御方扣 1 盾
- **包子 vs 攒气**：掉 1 血，结算结束
- **防御 vs 攒气**：无事
- **防御 vs 防御**：无事
- **攒气 vs 攒气**：双方各 +1 气 +1 盾

> 没有技能、没有 CD、没有封盾、没有多连。包子也不存在"3 连破防"这条。

### 2.1 边界（已实现口径）

- **盾 0 出防御 = 裸防**：`can_use_action` 判非法（超时兜底自动改攒气）；若仍被强行出招，按**裸防**结算——不挡任何攻击，被包子 / 破防技 / 终极技打中即掉血（经典 1 血，直接判负）。对攒气仍无事。
- **平局重开上限**：40 回合双方存活且血同 → 平局并**重开本局**（不清比分），最多重开 3 次；**第 4 次平局整场判平**（`draw_replay_max = 3`，由 `is_match_over()` 收口）。
- **越界出招兜底**（规则层自防御，2026-10-27）：联机外部数据强出本模式禁用动作（技能 / 劝降 / 越界值）→ 结算层按「超时兜底自动改攒气」兜底为**攒气**，保证"没有技能、没有 CD、没有封盾"不被绕过；包子族非法多连仍按上限收口（只算 1 包）。

## 3. 与课间模式（v2）的差异

| 参数 | 经典 | 课间（v2） |
|---|---|---|
| 血量 | 1 | 4 |
| 气上限 | 5 | 10 |
| 盾上限 | 3 | 3 |
| 包子连数 | **1** | 1–3 |
| 可用动作 | 3 个基础动作 | 11 技能 + 劝降 |
| 技能解锁 | 无 | 1–8 分依次解锁 |
| 胜负 | 一局定胜负 | 先到 12 分 |
| 40 回合 | 比血 → 血同判平 | 比血 → 血同判平 |
| 平局保底 | 不适用（平局重开本局，最多 3 次；第 4 次整场判平） | 第 3 次平局起双方各 +1 分 |

## 4. 平衡备注

- **防御是唯一防线**：盾 3，防御一次 −1，攒气一次 +1 —— 净收支打平，所以"防御多久"本身就是决策。
- **核心读招**：对方攒气时出包子 = 直接赢；对方防御时攒气/防御 = 攒资源。
- 盾打空后只能靠攒气回盾，而攒气是裸的 → 残局会进入"赌对方攒不攒"的高压状态。
- 一局通常 5–10 回合（约 30–60 秒），也可能 3 回合速杀——AI 难度要按"何时攒、何时压"来区分，而不是靠数值。
